**Hasil: 22/22 skenario Browser UAT otomatis lulus.**

Source yang diuji: `c5c0539e771b7cca723402fab17fa7cd499995ec`, branch lokal master, versi 9.5.2.
Tidak ada perubahan kode aplikasi, commit, push, deployment atau migration pada database aktif dalam pekerjaan UAT ini.

## Lingkungan dan cara pengujian

- Chrome headless 155.0.8059.84 dengan Playwright Core 1.64.1; PHP 8.5.10 dan MariaDB 10.4.32.
- Desktop 1440×1000; mobile Chromium emulation 390×844, touch aktif, timezone browser Asia/Bangkok. Ini bukan pengujian pada perangkat fisik, Safari/iOS atau Firefox.
- Instance MariaDB baru pada loopback port 3317 dengan datadir TEMP, schema berawalan santovate_crm_test_uat_, serta akun khusus berawalan santovate_test_ yang hanya diberi akses ke schema tersebut.
- Aplikasi UAT loopback port 8095 menjalankan source dan bundle V9.5.2 yang ada. Seluruh 26 migration dijalankan pada schema baru.
- Satu perusahaan fiktif dibuat sebelum dua migration identitas, kemudian seluruh nilai baris lama dibandingkan sebelum/sesudah migration dan setelah seluruh UAT.
- IsolatedDatabaseGuard dipasang sebelum provider aplikasi. Koneksi yang tersedia hanya SQLite memory dan mysql_testing. Koneksi database development dibuang dari konfigurasi aplikasi UAT.
- APP_ENV=testing; login menggunakan form autentikasi sebenarnya, sesi file TEMP, dan request browser melalui middleware web. Tidak ada route bypass login atau perubahan source untuk memudahkan tes.
- Flag B2C ON hanya pada konfigurasi UAT. Flag OFF diuji pada sebagian skenario; .env aplikasi asli tidak diubah.
- Semua akun, nomor, perusahaan, individu, pesan dan transaksi adalah fixture fiktif; tidak menyalin data pelanggan aktif.
- HTTP API keluar dicegah pada backend, mailer diarahkan ke log null, dan semua request browser non-localhost diblokir.
- Kontak WhatsApp disiapkan melalui service inbound dengan payload fiktif. Transport webhook Meta, signing Meta dan pengiriman WhatsApp sesungguhnya tidak diuji di browser ini.
- Suite final diulang dari fixture baru setelah penyesuaian locator label pada harness. Tidak ada patch pada aplikasi untuk membuat suite lulus.

## Audit trigger deployment: terkonfirmasi dari source, tidak dieksekusi

DEPLOY_SANTOVATE.ps1 default ke master, melakukan fetch/pull (baris 173–174), lalu memanggil scripts/deploy/deploy-production.sh (baris 176).
Script shell menarik branch target lagi (baris 50–51), kemudian menjalankan **artisan migrate --force** (baris 57).
Jadi flag B2C OFF **tidak mencegah dua migration V9.5.2 diterapkan** jika script deployment dijalankan.

Tidak ada koneksi SSH/SCP ke Hostinger dalam UAT ini. Versi source/schema yang sedang aktif di Hostinger belum diverifikasi dalam sesi ini; tidak dinyatakan sudah berubah atau sudah diaudit.
